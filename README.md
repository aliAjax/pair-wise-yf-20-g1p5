# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 节目段落顺延

- 每个段落可在「节目段落调整」表中修改时值（持续时间），其后的段落整体顺延，直到下一个**定格**段落前；已勾选定格的段落永不移动，修改时值时实时预览受影响范围。
- 顺延候选先经整场校验：点火/燃放落入**停火窗**、同时燃放的**相邻点位安全距离不足**（间距 < 双方安全距离之和）、同点位时段重叠、**越过配乐终点**，任一命中则整次调整拒绝并列出全部冲突，原时间轴、点位表与统计保持不变。
- 校验通过的调整自动保存到浏览器 localStorage，刷新后继续；「重置脚本」可恢复初始数据。
- 页面包含：燃放时间轴（点位泳道 + 停火窗 + 配乐终点）、点位平面图（安全距离圈 + 相邻间距）、型号清单、冲突提示、整场预览走带（8 倍速）与摘要导出。

## 本地运行

npm run dev
