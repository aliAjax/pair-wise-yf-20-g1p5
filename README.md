# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62008

## 节目段落顺延

- 每个段落可在「时值调整」表中修改时值（秒），确认后触发整体顺延。
- 排在其后的段落按同一差值平移，遇到下一个 📌 定格段落即停止；已勾选的定格段落不得移动。
- 顺延后逐项校验：点火落入停火窗、时段重叠段落的相邻点位安全距离不足、段落结束越过配乐终点——任一命中则整次调整拒绝并列出全部冲突，原时间轴、点位表与统计保持不变。
- 校验通过的调整保存到浏览器 localStorage（键 `hxyfront-62008-schedule`），刷新后继续生效；「恢复默认编排」可清除。
